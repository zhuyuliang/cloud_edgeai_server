# Web 云平台接口对接服务 API 文档

> 适用版本：Admin v2.3.5+（集群管理平台对接接口）
> 服务端：`Admin`（Django），默认端口 `9001`
> 源码入口：`Admin/app/urls.py` 中标注为「适配集群管理平台」的路由

---

## 1. 概述

设备端（Admin 服务）对外提供一组 `open/*` 接口，供 **Web 云平台 / 集群管理平台** 对接使用，实现以下能力：

- 设备发现与接入（集群平台添加设备）
- 视频流（媒体源）查询、删除、转发代理、转推代理
- 布控（算法任务）查询、启动、停止、删除
- 视频流 / 算法流 / 核心进程数据同步

### 1.1 基础地址

```
http://<设备IP>:9001
```

其中 `9001` 为 `config.json` 中 `adminPort` 配置的 Admin 服务端口。

### 1.2 认证方式

所有集群平台接口（`open/*`、`stream/open*`、`control/open*`）均要求请求头携带集群密钥：

| 请求头 | 说明 |
| --- | --- |
| `Eai-Secret` | 集群密钥，与设备端 `config.json` 中的 `clusterSecret` 一致 |

约定：

- 若设备端 `clusterSecret` 为空，则不校验 `Eai-Secret`；
- 若设备端 `clusterSecret` 非空，则要求请求头 `Eai-Secret` 与其完全一致，否则返回 `code=0` + `msg="Eai-Secret 校验失败"`。

### 1.3 通用响应格式

所有接口统一返回 JSON（`Content-Type: application/json; charset=utf-8`）。

**业务码约定：**

| code | 含义 |
| --- | --- |
| `1000` | 成功 |
| `0` | 失败（具体原因见 `msg`） |

通用结构：

```json
{
  "code": 1000,
  "msg": "success"
}
```

分页类接口额外返回 `data`、`pageData`；发现类接口额外返回 `info`。

## 2. 接口列表总览

| 分类 | 方法 | 路径 | 说明 | 认证 |
| --- | --- | --- | --- | --- |
| 设备发现 | GET | `/open/discover` | 集群平台添加设备，返回设备信息 | `is_auth=1` + `Eai-Secret` |
| 视频流 | GET | `/stream/openIndex` | 查询视频流列表（RTSP，分页） | `Eai-Secret` |
| 视频流 | POST | `/stream/openDel` | 删除视频流（单条/全部） | `Eai-Secret` |
| 视频流 | POST | `/stream/openAddStreamProxy` | 开启视频流转发代理 | `Eai-Secret` |
| 视频流 | POST | `/stream/openDelStreamProxy` | 关闭视频流转发代理 | `Eai-Secret` |
| 视频流 | POST | `/stream/openAddStreamPusherProxy` | 开启视频流转推代理 | `Eai-Secret` |
| 布控 | GET | `/control/openIndex` | 查询布控列表（分页） | `Eai-Secret` |
| 布控 | POST | `/control/openStartControl` | 启动布控 | `Eai-Secret` |
| 布控 | POST | `/control/openStopControl` | 停止布控 | `Eai-Secret` |
| 布控 | POST | `/control/openDel` | 删除布控 | `Eai-Secret` |
| 数据同步 | GET | `/open/getAllStreamData` | 查询视频流列表（简化） | `Eai-Secret` |
| 数据同步 | GET | `/open/getAllAlgroithmFlowData` | 查询算法流列表 | `Eai-Secret` |
| 数据同步 | GET | `/open/getAllCoreProcessData` | 查询核心进程数据 | `Eai-Secret` |
| 数据同步 | GET | `/open/getAllCoreProcessData2` | 查询核心进程数据（含统计） | `Eai-Secret` |

### 1.4 登录说明

集群平台接口（`open/*`、`stream/open*`、`control/open*`）在中间件层统一使用 `Eai-Secret` 鉴权，**不依赖登录会话**，鉴权通过后直接放行；因此无论 `skipLoginAuth` 是否开启，集群平台均可正常调用。其余 Web 页面接口仍遵循原有登录规则。

## 3. 设备发现

### 3.1 集群平台添加设备（设备发现）

**接口：** `GET /open/discover`

**用途：** 集群平台添加设备时，探测设备身份信息。

**请求参数（Query）：**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `is_auth` | string | 是 | 必须为 `1`，否则返回 `需要 is_auth=1` |

**请求头：**

| 请求头 | 必填 | 说明 |
| --- | --- | --- |
| `Eai-Secret` | 条件必填 | 与 `clusterSecret` 一致 |

**请求示例：**

```http
GET /open/discover?is_auth=1 HTTP/1.1
Host: <设备IP>:9001
Eai-Secret: 你的edgeaiSafe集群密钥
```

**响应示例（成功）：**

```json
{
  "code": 1000,
  "msg": "success",
  "info": {
    "system_name": "nanopc-t6-edgeai",
    "machine_node": "arm64",
    "project_ua": "admin",
    "project_version": "2.3.5",
    "project_flag": "open",
    "project_built": "2024-01-01 00:00:00",
    "project_start_timestamp": 1700000000,
    "code": "node-001",
    "name": "nanopc-t6-edgeai",
    "describe": "nanopc-t6-edgeai-describe",
    "host": "http://127.0.0.1:9001"
  }
}
```

**响应字段说明：**

| 字段 | 说明 |
| --- | --- |
| `system_name` | 系统名称 |
| `machine_node` | 机器节点（架构/型号） |
| `project_ua` | 项目 UA 标识（`PROJECT_UA`） |
| `project_version` | 项目版本号（`PROJECT_VERSION`） |
| `project_flag` | 项目标记（`PROJECT_FLAG`） |
| `project_built` | 构建时间 |
| `project_start_timestamp` | Admin 服务启动时间戳 |
| `code` | 设备编号（`config.json` 的 `code`） |
| `name` | 设备名称 |
| `describe` | 设备描述 |
| `host` | Admin 服务地址（`http://<adminHost>:<adminPort>`） |

**失败示例：**

```json
{ "code": 0, "msg": "Eai-Secret 校验失败" }
```

| `ps` | int | 否 | `10` | 每页条数（取值范围 10~20） |

### 4.2 删除视频流

**接口：** `POST /stream/openDel`

**用途：** 删除单个或全部 RTSP 视频流。

**请求参数（Body，支持表单或 JSON）：**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `handle` | string | 否 | `one`（单条，默认）或 `all`（全部） |
| `code` | string | 条件必填 | `handle=one` 时必填，视频流编号 |

**请求示例：**

```http
POST /stream/openDel HTTP/1.1
Host: <设备IP>:9001
Content-Type: application/json

{ "handle": "one", "code": "cam_xxxx" }
```

**响应示例：**

```json
{ "code": 1000, "msg": "success" }
```

```json
{ "code": 0, "msg": "该视频流不存在" }
```

`handle=all` 时返回：`{ "code": 1000, "msg": "成功N条，失败M条" }`

### 4.5 开启视频流转推代理

**接口：** `POST /stream/openAddStreamPusherProxy`

**用途：** 将本地某路流（`stream_app/stream_name`）转推到目标 RTSP 地址（v3.502 新增）。该接口与媒体源表无关，直接下发 ZLMediaKit。

**请求参数（Body，支持表单或 JSON）：**

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `stream_app` | string | 是 | - | 源流应用（app） |
| `stream_name` | string | 是 | - | 源流名称（stream） |
| `dst_stream_app` | string | 是 | - | 目标流应用 |
| `dst_stream_name` | string | 是 | - | 目标流名称 |
| `dst_host` | string | 是 | - | 目标主机 IP/域名 |
| `dst_rtsp_port` | int | 否 | `554` | 目标 RTSP 端口 |
| `dst_http_port` | int | 否 | `80` | 目标 HTTP 端口（预留） |
| `dst_secret` | string | 否 | - | 目标鉴权密钥（预留） |

目标地址拼装规则：`rtsp://<dst_host>:<dst_rtsp_port>/<dst_stream_app>/<dst_stream_name>`

**响应示例：**

```json
{ "code": 1000, "msg": "success", "key": "<转推key>" }
```

```json
{ "code": 0, "msg": "错误信息", "key": "" }
```

## 5. 布控管理

### 5.2 启动布控

**接口：** `POST /control/openStartControl`

**用途：** 启动指定布控任务。启动前会校验摄像头在线状态（不在线先尝试启动），并校验算法是否存在。

**请求参数（Body，支持表单或 JSON）：**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | string | 是 | 布控编号 |

**响应示例：**

```json
{ "code": 1000, "msg": "布控成功" }
```

常见失败：

```json
{ "code": 0, "msg": "请求参数不合法" }
{ "code": 0, "msg": "该布控算法不存在" }
{ "code": 0, "msg": "摄像头启动失败：..." }
{ "code": 0, "msg": "系统正在处理其他布控操作，请稍后重试" }
```

## 7. 附录

### 7.1 相关配置项（`config.json`）

| 配置项 | 说明 |
| --- | --- |
| `adminPort` | Admin 服务端口（默认 `9001`） |
| `code` | 设备编号（设备发现返回） |
| `name` / `describe` | 设备名称 / 描述 |
| `clusterSecret` | 集群密钥（`Eai-Secret` 校验依据） |
| `skipLoginAuth` | 是否免登录（`true` 时 `open/*` 接口可直接访问） |

### 7.2 源码位置

- 路由定义：`Admin/app/urls.py`
- 设备发现 / 数据同步：`Admin/app/views/api.py`（`api_discover`、`api_getAllStreamData` 等）
- 视频流集群接口：`Admin/app/views/StreamView.py`（`api_openIndex`、`api_openDel` 等）
- 布控集群接口：`Admin/app/views/ControlView.py`（`api_openIndex`、`api_openStartControl` 等）
