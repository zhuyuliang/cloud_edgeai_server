## 二、各界面功能明细

### 1. 控制面板（仪表盘）`/`

**页面模块：**
- **CPU 利用率**：实时图表（Highcharts 曲线），展示管理端主机 CPU 使用率。
- **内存利用率**：实时图表展示内存使用率。
- **存储利用率**：实时图表展示磁盘使用率。
- **流媒体服务器**：
  - 进程状态（在线/离线）
  - 在线视频数量统计
- **系统信息**：
  - 机器（Machine）
  - 系统（OS 名称）
  - 运行时长（启动时间计时）
  - CPU / 内存 / 存储 使用率百分比

**数据接口：**
- `index/updateDashboardData`：更新仪表盘数据
- `index/getDashboardData`：获取仪表盘数据
- `index/getDashboardPlayerData`：获取大屏播放数据
- `index/getNewAlarm`：获取最新报警

**相关页面：**
- `dashboard.html`：大屏管理（深色科技风大屏，供多屏监控展示）

---

### 2. 节点管理 `/node/index`

**功能描述：** 边缘 AI 节点的统一接入、状态监控与管理。

**主要功能：**
- **节点列表**：分页展示，含节点编号、昵称、版本、地址、状态等字段。
- **状态监控**（状态徽章）：
  - 未同步
  - 在线
  - 掉线
  - 版本不支持
- **操作按钮：**
  - 添加节点（弹窗表单）
  - 编辑节点
  - 删除节点
  - 全量同步节点
  - 单个节点同步
- **导入更新**：批量导入/更新节点。
- **节点详情**：查看节点详细信息。

**数据接口：**
- `node/add` / `node/edit`：添加/编辑节点
- `node/openDel`：删除节点
- `node/openSync`：同步节点
- `node/openImportUpdate`：批量导入更新
- `node/openNodeDetail`：节点详情

---

### 3. 报警管理（事件/车牌/人脸）`/alarm/event` `/alarm/carplate` `/alarm/face`

**功能描述：** 汇聚边缘节点上报的报警信息，按 `alarm_category` 分类分页展示，进行审核处理与导出。三个页面共用 `alarm/list.html` 模板。

**告警分类（alarm_category）：** 0事件 / 1车牌 / 2人脸 / 3计数

**告警状态（state）：** 0未读 / 1未处理 / 2已处理 / 3误报 / 5逻辑删除

**主要功能：**
- **报警列表**：分页展示报警记录（级别：普通/警告/严重；风险等级：低/中/高；状态：未读/未处理/已处理/误报），支持分类/节点/状态筛选与关键字搜索。
- **深链详情**：`?alarm_code=xxx` 自动打开详情弹窗（仪表盘大屏跳转入口）。
- **报警审核**：
  - 审核确认为已处理（仅本地改库，不回传节点）
  - 审核确认为误报
  - 标记已读
  - 填写审核备注（deal_info）
- **多媒体查看**：
  - 报警视频回放（支持 wav 音频）
  - 报警图片查看（多图拼接预览）
- **批量操作**：
  - 批量已读处理
  - 批量删除（逻辑删除，state=5）
  - 批量导出
- **报警导出**：导出报警数据。

**数据接口：**
- `alarm/openIndex`：报警列表（含未读角标计数）
- `alarm/openHandle`：报警处理（审核/已读/删除）
- `alarm/openExport`：导出报警
- `alarm/openInfo`：报警详情
- `alarm/openPush`：边缘报警签名推送入库（`event_id` 幂等去重）
- `alarm/openUploadFile`：边缘报警媒体文件接收

**模板：** `templates/app/alarm/list.html`

---

### 3.1 计数告警 `/alarm/count`

**功能描述：** 展示边缘节点上报的计数类告警（客流/车流统计等），支持手动清零与历史查询。表 `eai_node_statistic_alarm`。

**主要功能：**
- **计数列表**：节点、布控编号、算法任务、当前计数、进入数、离开数、累计总量、清零策略（手动/每小时/每日/每周/每月）、上次清零时间、更新时间。
- **清零**：手动将任务计数清零（转发边缘 `alarms/openResetCount`，并归档旧周期到历史表）。
- **历史**：跳转计数历史页查看周期归档记录。

**数据接口：**
- `alarm/openStatisticIndex`：计数列表（关联节点昵称）
- `alarm/openResetCount`：计数清零（唯一回传边缘的例外操作）

**模板：** `templates/app/alarm/count.html`

---

### 3.2 计数历史 `/alarm/count/history`

**功能描述：** 计数任务每个清零周期归档的汇总记录（表 `eai_node_statistic_history`），支持趋势图与导出。归档触发点：边缘周期清零推送（reset）与云端手动清零（manual）。

**主要功能：**
- **历史列表**：首行为进行中周期（`live_` 前缀），其后为已归档周期（含周期起止时间、进入/离开/总量）。
- **趋势图**：ECharts 折线图展示计数趋势。
- **删除**：删除已归档历史（拒绝删除进行中 `live_` 前缀）。
- **导出**：导出历史 xlsx（ajax blob 下载）。

**数据接口：**
- `alarm/openStatisticHistory`：历史列表（GET）
- `alarm/openDeleteStatisticHistory`：删除历史（POST，拒 `live_`）
- `alarm/openExportStatisticHistory`：导出历史 xlsx

**模板：** `templates/app/alarm/count_history.html`（依赖 `static/vendors/echarts/`）

---

### 4. 视频管理 `/stream/index`（v2 壳模式）

**功能描述：** 节点视频流查询、转发代理、转推代理与多协议播放。**v2 版为云端壳页（节点下拉 + iframe 双跳代理）内嵌边缘统一媒体源管理页**，实际管理界面由边缘节点渲染，云端经 `/proxy/node/<node_code>/stream/index?embed=1` 代理注入（自动重写边缘页面中的绝对路径/接口地址）。

**主要功能：**
- **视频流列表**：按节点筛选，展示流名称、流编码、转发状态等。
- **转发代理**：
  - 单个流：开启转发 / 停止转发
  - 全部开启转发
  - 全部停止转发
- **转推代理**：流媒体转推配置。
- **播放**：多协议播放（RTSP / HLS / HTTP-FLV / WS-MP4）。
- **导入**：批量导入视频流。
- **删除**：删除视频流。

**数据接口：**
- `stream/openIndex`：视频流列表
- `stream/openAddStreamProxy`：添加转发/转推代理
- `stream/openDelStreamProxy`：删除代理
- `stream/openHandleAllStreamProxy`：批量处理代理
- `stream/openDel`：删除视频流
- `stream/player`：播放器页面
- `proxy/node/<node_code>/<path>`：节点页面代理（iframe 双跳：云端登录态 + 边缘 Eai-Secret；`embed=1` 由云端注入避免边缘渲染整页框架）

**模板：** `templates/app/stream/index_v2.html`（壳页）

---

### 5. 单屏播放器 `/stream/player`

**功能描述：** 单屏多协议视频播放器，用于视频流的实时观看。

---

### 6. 布控管理 `/control/index`（v2 壳模式）

**功能描述：** 向边缘节点下发布控（算法）任务，支持全生命周期管理。**v2 版为云端壳页（节点下拉 + iframe 双跳代理）内嵌边缘统一布控管理页**（`/proxy/node/<node_code>/controls?embed=1`），添加/编辑页面对 iframe 内跳转泄漏做了 Referer 兑底重定向，避免整壳嵌套叠加。

**主要功能：**
- **布控列表**：分页展示布控任务（关联算法流/业务算法）。
- **布控操作（单个）：**
  - 启动布控
  - 停止布控
  - 复制布控
  - 查看布控日志
  - 删除布控
  - 布控配置/参数设置
- **批量操作**：
  - 全部删除
  - 批量启动 / 批量停止
- **布控日志**：弹窗查看布控日志内容。

**数据接口：**
- `control/openIndex`：布控列表
- `control/add` / `control/openAdd`：添加布控
- `control/edit` / `control/openEdit`：编辑布控
- `control/openDel`：删除布控
- `control/openCopy`：复制布控
- `control/openLog`：布控日志
- `control/openSettings`：布控配置
- `control/openHandleAllControl`：批量操作
- `control/openStartControl` / `control/openStopControl`：启动/停止

**模板：** `templates/app/control/index_v2.html`（壳页）、`add.html`、`iframe.html`

---

### 7. 用户管理 `/user/index`

**功能描述：** 系统用户的登录认证与增删改查。

**主要功能：**
- **用户列表**：分页展示用户信息。
- **添加用户**：弹窗表单录入用户（用户名、密码等）。
- **编辑用户**：修改用户信息、重置密码（新密码 + 确认新密码）。
- **删除用户**：删除用户。
- **用户详情**：查看用户详细信息。
- **登录/退出**：
  - 图形验证码（`captcha`）
  - RSA 加密登录（jsencrypt 前端 + pycryptodome 解密）

**数据接口：**
- `user/add` / `user/edit`：添加/编辑用户
- `user/postDel`：删除用户
- `user/api_openUserDetail`：用户详情
- `captcha` / `login` / `logout`：验证码/登录/退出

---

### 8. 系统功能 — 启动配置 `/system/config`

**功能描述：** 系统运行配置与展示信息的查看、编辑、保存与日志导出。

**主要功能：**
- **系统基本信息**：读取 `settings.json`（系统名称、欢迎语、Logo、底部信息、作者等）。
- **运行配置**：读取/编辑 `config.json`（端口、密钥、目录、验证码开关等）。
- **保存配置**：保存系统设置。
- **日志导出**：导出系统日志（打包下载）。

**数据接口：**
- `system/postSaveSettings`：保存设置
- `system/postExportLogs`：导出日志

---

### 9. 系统功能 — 关于系统 `/version/index`

**功能描述：** 系统版本信息展示与在线更新检查。

**主要功能：**
- **版本信息**：展示当前版本号（PROJECT_VERSION）与构建标识（PROJECT_FLAG）。
- **检查更新**：对接云服务在线检查新版本。
  - 新版本号、发布日期
  - 更新内容（updateContent）
  - 历史版本地址、下载地址

**数据接口：**
- `version/getCheckVersion`：检查版本更新
